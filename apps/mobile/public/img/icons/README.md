# 界面图标（48 张）

全站界面上的**所有**图案：区块标题前面那对「❯❯」、列表行的 `›`、链接尾的 `→`、
收藏的实心/空心两颗心、今日安排的状态点……从前它们是**文字符号与 emoji**
（`❯❯` `→` `＋` `×` `✓` `❤` `♡` `●` `↻` `⌃` `🍳` `🍽` `📷` `✅` …）。

用户 2026-10-16 的要求：「看一下现在软件中所有的图标，一般都用的是符号图标，
需要全部改为用图片生成，生成一张即可，然后裁剪，不要用符号图标了。」

## 为什么必须换掉符号（这不是审美问题）

文字符号（`＋`/`×`/`✓`/`●` 这一族）的长相与**字号、基线、字体**绑在一起，同一个字
在安卓与 iOS 上不一样大、位置也不一样。本项目为此栽过三次，每次都留下过实测数据：

| 符号 | 实测偏差 | 记录 |
| --- | --- | --- |
| `＋`（U+FF0B） | 在 38px 圆钮里**偏左 3.7px、偏下 2.7px** | `src/components/icons/TabIcons.tsx` |
| `×`（U+00D7） | 在同一颗钮里**偏下 3.4px** | 同上 |
| `●`（状态点） | 大小随字体走；而且它后面那个空格会把「● 还没人点」撑成"两个元素" | `src/pages/kitchen/components/TodayMeals.tsx` |

emoji（`🍳` `🍽` `📷` `✅`）更不可控：它们由**系统字体**画，安卓与 iOS 完全是两套画风，
在本项目的手绘水彩界面里像是从别的 App 抠来的。

换成图片之后，**尺寸与位置由我们说了算**（`width`/`height` + `vertical-align: middle`），
画风与 `public/img/corner/`、`ingredients/` 同一套手绘水彩语汇。

## 从哪来

由 AI 生成（`gpt-image-2.5-sunburst`，走 `image-generation` 技能），**一张图里排十几个**
再按格裁开——一张里出十几个才保证风格一致，分批生成会出现"这批的橙偏红、那批偏黄"。

| 原表（`generated-images/`，不入库） | 内容 |
| --- | --- |
| `icons-solid-a.png` | 16 个「事物的图标」：书 / 篮子 / 锅 / 沙漏 / 筷 / 冰 / 相机 / 对话框 / 房子 / 夹板 / 米饭 / 锁 / 星 / 循环 / 对勾 / 叉 |
| `icons-solid-b.png` | 16 个：「盘子 / 一家三口 / 辣椒 / 铃 / 骰子 / 星星 / 拼图 / 日历 / 铅笔 / 购物车 / 平底锅 / 灯泡 / 实心心 / 空心心 / 青菜 / 放大镜」 |
| `ui-marks.png` | 13 个「方向与增减记号」：加 / 减 / 裸勾 / 裸叉 / 单箭头（右·下·上）/ 双箭头 / 左右箭头 / 右上箭头 / 漏斗 / 相册 |
| `ui-dots.png` | 3 个状态点：鼠尾草绿 / 琥珀金 / 暖灰褐 |

> 用户说的「生成一张即可，然后裁剪」——一张只能稳稳出十六个上下（再多就糊），
> 40 多个挤一张等于白生成。所以按 **事物 / 记号 / 状态点** 分成四张，
> 仍然是"拼图 + 裁剪"，而不是一个图标调一次生成（那才会风格散掉）。

## ⚠️ 生成时底色必须是纯品红 `#FF00FF`

**不能要"透明背景"**：模型嘴里的 transparent 画出来是**棋盘格图案**
（白 `#FDFDFE` + 灰 `#E8E8E8` 两种格子）——它把"透明"当成一种纹理画进了图里，
而那层格子会被当成图的一部分显示在米色底上。

品红是安全的：图标配色（奶油 / 蜜桃橙 / 砖红 / 鼠尾草绿 / 土褐）里绝不会有它，
所以可以整片抠掉、且不碰图标内部的白（碗、盘子、米饭都是白的）。

## 裁剪与压缩

```bash
# 1) 裁成格子（4×4 或 2×2）
magick sheet.png -crop 4x4@ +repage /tmp/tiles/t-%d.png

# 2) 抠掉品红底 → 去边 → 压到 128×128（与 ingredients/ 同一套，差别只在尺寸）
magick m-0.png -fuzz 22% -transparent '#FF00FF' -trim +repage \
  -resize 128x128 -background none -gravity center -extent 128x128 \
  -strip -colors 128 out.png
```

- `-fuzz 22%`：品红与图标边缘的抗锯齿像素是渐变的，不放宽会留一圈紫边；
- `-trim` + `-extent`：去掉 AI 图自带的边距、再补成正方，否则 48 张的"视觉大小"忽大忽小；
- `-colors 128`：48 张总计压到 **348KB**（单张 3～8KB），40px 以内的显示尺寸下肉眼无差。

⚠️ **`-trim` 的副作用要在用时补回来**：裁过的图**墨迹正好占满整格**，
所以放进文字里就是零距离（实测「点这里问 AI」到箭头是 **0px**，符号年代不存在这个问题
——`→` 这个字形自带边距）。补的办法是 `Icon` 上的 `className="icon--trail"`
（跟在文字后）与 `"icon--lead"`（站在文字前），见 `src/components/icons/icon.scss`。

## 加新图标

1. 在 `src/components/icons/Icon.tsx` 的 `IconName` 里加名字（名字 = 文件名）；
2. 生成一张新表（或单张），按上面的命令裁切压缩，文件名用那个名字；
3. 用 `<Icon name="…" size={…} />`。

**带圈与不带圈的两套别混**（`Icon.tsx` 里那段 ⚠️ 写清楚了）：
`check`/`cross` 是**带底圆的插图**（画"一个状态"用），`tick`/`close` 是**裸记号**
（压在别的颜色上用）。用错很具体：带圈的图 `white` 一下会变成**一整块白饼**。

颜色：这批是**位图**，`currentColor` 对它无效——需要换个颜色就写一条滤镜
（`.icon--white` / `.icon--trail` 都在 `icon.scss` 里）。
