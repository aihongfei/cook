# 食材图标（M6 / F6-03）

48 张常用食材的手绘图，用于冰箱录入抽屉的「常用食材」快选，以及库存列表里每样食材的小图。

## 从哪来

由 AI 生成（`gpt-image-2.5-sunburst`，走 `image-generation` 技能），**一张图 4×4 排 16 样**，
再裁成 16 张独立小图——一张里出 16 个的好处是**风格一致**：分批生成会出现"这批的番茄偏红、
那批偏橙"这种不一致，摆在一屏里尤其明显。

生成时的风格约束（与 `public/img/corner/` 的角落插画同一套手绘水粉语汇）：
> 手绘水彩、贴纸排版、每格一样食材居中在奶白色圆角方块上、暖色调（奶油/蜜桃/橙/鼠尾草绿/土褐）、
> 柔和阴影、俯视三分之四视角、无文字无标签无水印、每格间距均匀便于裁剪。

三张表的分组与顺序（行序即裁剪顺序，见 `src/pages/fridge/ingredients.ts` 的 id 顺序）：

| 表 | 内容（4×4） |
| --- | --- |
| `sheet-veggies` | 鸡蛋 / 牛奶 / 酸奶 / 豆腐；小白菜 / 大白菜 / 菠菜 / 西兰花；西红柿 / 黄瓜 / 胡萝卜 / 土豆；洋葱 / 青椒 / 香菇 / 玉米 |
| `sheet-meat` | 五花肉 / 鸡胸 / 牛肉 / 排骨；鱼 / 虾 / 鱿鱼 / 蛤蜊；大米 / 挂面 / 面粉 / 面包；姜 / 蒜 / 葱 / 干辣椒 |
| `sheet-seasoning` | 生抽 / 醋 / 食用油 / 盐；糖 / 香油 / 蚝油 / 豆瓣酱；苹果 / 香蕉 / 橙子 / 柠檬；草莓 / 葡萄 / 梨 / 西瓜 |

三张原表（各约 2MB）与其它 AI 生成的原图一起放在仓库根的 `generated-images/`（**不入库**，
与 `corner/` 的 Hi 图同一个规矩：只提交压好的成品）。想重新裁一遍就从那儿取；表没了也不影响跑，
只是要重新生成——**重生成不会是同一批图**（AI 出图非确定），所以别随手删。

## 裁剪与压缩（照 `corner/` 那套做法）

```bash
# 1) 裁成 16 格（4×4）
magick sheet.png -crop 4x4@ +repage /tmp/tiles/tile-%d.png

# 2) 按 ingredients.ts 里的 id 命名，再统一压到 152×152
magick in.png -trim +repage -resize 152x152 -background none \
  -gravity center -extent 152x152 -strip -colors 128 \
  -define png:compression-level=9 out.png
```

`-trim` 去掉 AI 图自带的边距、`-extent` 补成正方（否则 48 张的"视觉大小"会忽大忽小）；
`-colors 128` 把总计从 5.2MB 压到 **516KB**（单张 7～9KB），152px 显示下肉眼无差（并排比过）。
显示尺寸：录入选区 44px、清单小图 32px——都远小于 152，留了高分屏余量。

## 加新食材

1. 在 `ingredients.ts` 里加一条预设（`id` 与图文件名一致）；
2. 生成一张新表（或单张），按上面的命令裁切压缩，文件名用那个 `id`;
3. 没有图也不会坏：`findPresetByName` 找不到就返回 `null`，界面退回中性占位
   （**不假装知道那是什么**——错图比没图更糟）。
