# 御膳 · 家庭小厨房

一个面向**家庭场景**的移动端应用：家人点菜、掌勺人回应，配合冰箱库存、备菜计划与菜谱库，解决"今天吃什么、家里有什么、还缺什么"。

## 它解决什么

- 家人想吃什么 → 点菜给掌勺人看（有状态流转，不是留言板）
- 掌勺人纠结做什么 → 按家庭口味/忌口过滤 + 随机配餐 + 常用组合
- 家里有什么 → 冰箱库存（含保质期、快过期提醒）
- 还缺什么 → 按最终菜单自动生成采购清单
