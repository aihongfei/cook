用户确认方向为「04 手绘水粉 · 插画」。已交付完整实现：

- 5 个 Tab：厨房（首页）/ 订单 / 发现 / 冰箱 / 我的，底部导航可点击切换。
- **笔绘素材**（`handpainted/assets/`，`gpt-image-2` 生成）：`hero.png` 厨房场景、`dish-tomato-egg.png`、`dish-ribs.png`、`dish-soup.png`、**`logo-t.png` 透明底手写品牌字（实际使用；`logo.png` 为非透明原图）**、**`cat-1.png`~`cat-5.png` 五个独立分类按钮图标**（由 `cats.png` 水彩长条**裁切**而来，`verify-boxes.png` 是裁切校验图）、`banner.png` 时令食材横幅、`basket.png` 蔬果篮（备用）。带文字的素材实测**中文字形正确**。
- **手写字体**：**ZCOOL KuaiLe（站酷快乐体）**，**SIL OFL 1.1（可商用）**；简体中文单文件 `fonts/zcool-kuaile-chinese-simplified-400-normal.woff2`（726 KB，经 fontsource 获取）。界面**全部功能文字**改用该字体（`--sans` 指向它），不再用默认字体。
- **分类按钮**：5 个**独立 DOM 按钮**（`<div class="cat"><img> + <span>`）——图标是笔绘图片，标签是手写字体的**真实文字**（可改文案、可翻译、可无障碍朗读）。之所以拆成 5 张：一张长条图没法做按钮交互与单独状态。
- **logo 遮挡**：改为**透明底 PNG**，直接落在插画上（**没有遮挡层**），只用三重复合 `drop-shadow` 加米色微光保证可读性。
- **底部导航两角的草**：手绘 SVG 小枝（茎 + 3 片叶，右侧镜像），替换了 emoji。
- **底色对齐**：生成素材背景实测为 `#FCF1D9~DC`，故把 `--cream` 调为 `#FCF1DA`，让素材与页面无缝衔接。
- 配色 token：`--cream:#FDF3E3` `--ink:#5A3520` `--orange:#E07B39` `--brick:#B94A2C`；分类粉彩色 `--peach/--sage/--butter/--rose/--teal`；圆角 18–22px。
- 手绘感图标（厨师帽 / 闪电 / 鸡腿 / 叶子 / 汤碗）为**内联 SVG 线描**，非位图。
