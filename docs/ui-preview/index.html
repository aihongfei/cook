御膳 · 三套 UI 方案对比

三套方案是同一套页面结构与交互，只有色彩、圆角、气质不同。每台手机里的底部 Tab（厨房 / 订单 / 发现 / 冰箱 / 我的）都能点击切换，筛选 chips 也能点。
看完直接告诉我选哪个（或组合，例如"C 的配色 + A 的圆角"）。

方案 A · 暖橙「家庭感」

大圆角、暖橘渐变、柔和阴影。最贴近参考图里的暖橙形态，主打亲和、有温度、家庭聚餐感。

单独打开 ↗

方案 B · 清新绿「料理感」

中等圆角、青绿主色、留白更多。偏干净、克制、工具属性强，长时间浏览不累眼。

单独打开 ↗

方案 C · 融合（橙主绿辅）

橙色做品牌与主操作，绿色只用于成功/健康/库存状态。既有家庭温度，又保留清爽的秩序感。

三套共用的设计规则（已标注）
尺寸基准 390×844（安卓主流机型）· 页面左右边距 16px · 卡片间距 12px · 卡片内边距 14–15px
字号阶梯 11 / 12 / 13 / 14 / 15 / 17 / 21px · 圆角 A 20px / B 16px / C 18px（小卡 11–12px）· 底栏高度 78px
色彩 token 每套 12 个（brand / brand-2 / bg / card / ink / ink-2 / line / soft / ok / warn / radius / shadow），切换主题只换这组变量。
页面内含的关键交互：点单状态徽标（待确认 / 已做好）、备注条、再点一次、今日安排进度、冰箱 AI 拍照识别入口、快过期提醒。
