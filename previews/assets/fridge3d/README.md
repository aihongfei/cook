## 源图从哪来

源渲染图在 `generated-images/fridge3d-closed.png` 与 `fridge3d-open.png`（**该目录已被 .gitignore 忽略**，不随仓库分发）。它们是 `gpt-image-2.5-sunburst` 通过 `image-generation` 技能出的，提示词要点：cute 3D clay render、retro fridge、glossy soft matte、Pixar 风玩具渲染、纯米色背景。

## 切图怎么做的（要重跑时照这个来）

用 ImageMagick（`magick`）：

1. **取门轮廓**：对关门图做**多种子容差泛洪**（`-fuzz 20% -fill none -draw "color x,y floodfill"`，种子取门面上的 4–6 个点），得到门的连通区域；再补内部孔洞（反相 → 从四角泛洪吃掉外部 → 剩下的就是孔 → 与原始掩膜取 `max`）。
2. **门板**：按掩膜 bbox 从关门图裁出，并向四外各扩 6px（盖住原图门与机身之间那条橙缝），套一个圆角矩形掩膜（半径 30/32）。
3. **底图**：把开门图对齐到关门图坐标系（缩放 91.8% + 偏移 `-43,+43`，实测值），再把它在门开口区域的像素贴到关门图上。
4. **门内侧**：从开门图里裁出左右两扇转开的门中较平坦的正面部分。

**两条容易翻车的点**（详见 R-53）：掩膜的"补孔"方向写反会让掩膜只剩把手；门的投影必须是**方向性**的（关着不投、越开影越远），无方向的模糊投影会在门四角形成灰边、把门变成一张贴纸。
